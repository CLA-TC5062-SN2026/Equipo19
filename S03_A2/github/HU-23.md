## Criterios de aceptación

- [ ] La pantalla de inicio de sesión muestra los mensajes exactos de RF-26-AC-2 y RF-26-AC-3 cuando la API los devuelve.
- [ ] Desde la pantalla se solicita la recuperación de contraseña y, con el enlace, se define una nueva (RF-26-AC-4).
- [ ] Al cerrar sesión o al recibir 401 por inactividad, la aplicación regresa a la pantalla de inicio de sesión (RF-26-AC-5, RF-26-AC-6).
- [ ] Funciona en Chrome y en Safari de Android e iOS (RNF-09).

## Justificación

Estimación: dos formularios y el manejo de la sesión en el cliente; la lógica ya está en la API de HU-01.
Prioridad: sin estas pantallas, ningún usuario real puede entrar al sistema.
